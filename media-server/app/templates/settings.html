The output fields are fixed by a JSON schema regardless of the prompt: caption, rating (sfw / suggestive / explicit), tags (outfit, location, activity, mood, framing, time_of_day) and extra_tags. Use the prompt to steer what goes in them: vocabulary, detail level, how to judge rating. Captions matter most, because they're what search matches against and what the chat model is told it sent.
